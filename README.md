# Арена Переговоров

Тренажёр переговорных навыков с ИИ-собеседником. Построен на Rust (Axum), использует Groq API для генерации диалогов и TTS/STT для голосового режима.

## Возможности

- **6 сценариев** — продажи, закупки, HR, управление, партнёрство, продление контракта
- **ИИ-диалог** — собеседник отвечает через Groq API (qwen3.8-27b), адаптируется к вашей стратегии
- **Метод SPIN** — отслеживание Situation / Problem / Implication / Need-payoff вопросов
- **Гарвардский метод** — фокус на интересах vs позициях, объективные критерии
- **Голосовой режим** — TTS/STT через Silero (опционально)
- **Аналитика** — оценка стратегии, аргументов и тона; инсайты и рекомендации
- **AI-генератор сценариев** — создание пользовательских сценариев через Groq
- **Админ-панель** — управление сценариями, пользователями, ролями и настройками
- **Dashboard** — выбор сценариев, история сессий, генерация новых сценариев

## Технологии

| Компонент | Технология |
|-----------|-----------|
| Backend | Rust + Axum |
| Шаблоны | Tera |
| БД | SQLite (rusqlite) |
| Auth | Argon2 + JWT |
| ИИ | Groq API (qwen3.8-27b) |
| TTS/STT | Silero TTS (опционально) |

## Быстрый старт

### 1. Клонирование

```bash
git clone https://github.com/username/negotiation-arena.git
cd negotiation-arena
```

### 2. Настройка окружения

```bash
cp .env.example .env
# Отредактируйте .env — вставьте ваш GROQ_API_KEY
```

### 3. Запуск

```bash
cargo run
```

Приложение будет доступно на `http://localhost:3001`.

### 4. Вход

- **Логин:** `admin`
- **Пароль:** `admin123` (или значение `ADMIN_PASSWORD` из .env)

## Структура проекта

```
negotiation-arena/
├── src/
│   ├── main.rs          # Сервер, маршруты, middleware
│   ├── engine.rs         # Сценарии, ИИ-генерация ответов, SPIN-анализ
│   ├── models.rs         # Данные: сценарии, диалоги, сессии
│   ├── db.rs             # SQLite, пользователи, JWT, история
│   └── tts.rs            # TTS/STT (Silero)
├── templates/            # Tera-шаблоны (HTML)
├── static/               # CSS, JS
├── .env.example          # Шаблон переменных окружения
└── Cargo.toml
```

## Переменные окружения

| Переменная | Описание | По умолчанию |
|-----------|----------|-------------|
| `GROQ_API_KEY` | API-ключ Groq | — (обязательно) |
| `JWT_SECRET` | Секрет для JWT-токенов | `change_me_to_a_strong_random_secret` |
| `ADMIN_PASSWORD` | Пароль администратора | `admin123` |
| `PORT` | Порт сервера | `3001` |
